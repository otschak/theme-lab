# Theme Lab

Static, self-contained page (`index.html`): theme list, chart viewer with EMA/SMA,
events, stage heatmap, patterns, supply and notes. No build step, no external
dependencies — Lightweight Charts and all data are embedded.

## Hosting

GitHub Pages deploys automatically on every push to `main`
(`.github/workflows/pages.yml`).

One-time setup: **Settings → Pages → Build and deployment → Source: GitHub Actions**.

## Local

Open `index.html` in a browser, or `python3 -m http.server` and visit
http://localhost:8000.
